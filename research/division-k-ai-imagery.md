## EXECUTIVE SUMMARY

The 2026 image-gen field specialized: no model one-shots a good text-bearing slide, and the hard benchmark proves it. Graphic-Design-Bench (arxiv 2604.04192, April 2026) tested GPT-5.4, Gemini-3.1-Pro, Claude-Opus-4.6 and found font-family accuracy 23.7%, styled-text-in-layout 33.5%, component detection 6.4% mAP: "faithful vector code generation remains largely unsolved." So the win is compositional, and Carter is already architected for it: AI makes ONE wordless focal asset, we set all type and layout in HTML with base64 fonts. Recraft V4 (Feb 2026) is the primary engine because it emits true editable SVG that inlines cleanly and scales to 2160x2700 with zero raster artifacts, via fal.ai at $0.08/vector call. The purple-teal gradient is the documented #1 slop tell for the cyber niche (Adam Wathan's Aug 2025 Tailwind-indigo apology, 1M+ views) and must be banned in code via an inline-SVG duotone that remaps every raster to brand hexes. New this pass: Recraft's own ToS reserves the right to embed watermarks/provenance, and Meta runs a content-based AI classifier independent of metadata, so the mandatory shotpls re-render strips container metadata but is not guaranteed label-evasion. Local FLUX.2 klein 4B (Apache-2.0, sub-second on a 4090) makes raster badge/emblem assets nearly free for the proven image-artifact style. Carter's own data anchors all of it: image-artifact decks did 47-65k views and 2.7-6.6k saves vs 10-18k / 100-570 for text-only.

## THE FINDINGS THAT MATTER (ranked)

### 1. No model one-shots a slide. This decides the whole architecture.
Graphic-Design-Bench (arxiv 2604.04192v1, April 2026) tested frontier models on 49 design tasks: only 2 mostly solved, 22 completely broken. Font-family accuracy 23.7% across 167 typefaces; styled-text OCR drops from 91% isolated to 33.5% when layout must be preserved; component detection 6.4% mAP@0.5. Paper's words: "faithful vector code generation remains largely unsolved." Source: K2, arxiv 2604.04192v1. Consequence: never generate a finished slide from any model. Generate ONE wordless asset; author layout and every text zone ourselves.

### 2. Recraft V4 is the primary engine because it is the only one that emits true editable SVG.
Released Feb 17-18 2026, four tiers (V4 Vector ~15s, V4 Pro Vector ~45s); V4.1 Vector is SVG-native-trained. Real paths and layers, not raster traced into an SVG wrapper. Style-lock across generations turns 20 prompts into a coherent SET, which is the single most important property for a repeatable deck. Exports SVG/PNG/PDF/Lottie. SVG inlines into our HTML and scales to 2160x2700 with zero raster artifacts, which no raster generator can promise. Sources: K1, K2 (recraft.ai/docs, replicate.com/blog/recraft-v4, toolchase.com). Verified pricing: fal.ai lists Recraft V4 Vector text-to-SVG at $0.08/image with commercial use (fal.ai/recraft-v4, confirmed this pass).

### 3. CRITICAL CORRECTION: Recraft is NOT a confirmed watermark-free primary. Its ToS reserves provenance embedding.
Scouts assumed Recraft output was clean because no source flagged a watermark. Primary source says otherwise. Recraft Terms of Service (recraft.ai/legal/terms, fetched this pass) states verbatim: Recraft "may (i) embed machine-readable metadata, watermarks, or other provenance information into Assets generated by the Services." This does not confirm it currently stamps SVG, but it invalidates treating Recraft as guaranteed-clean. Mitigation is already in the pipeline: SVGO strips SVG comments/metadata, and the shotpls re-render produces a fresh raster with no source-file container metadata. SVG (vector paths, no pixels) also cannot carry an in-pixel raster watermark like SynthID, which is a structural safety advantage of the vector path over any raster generator. Also from the ToS: paid subscribers own generated assets with full copyright assignment for commercial use; free-tier assets are NOT licensed for commercial use and stay owned by Recraft. So we MUST be on a paid Recraft/API tier. Source: K1 gap now closed, recraft.ai/legal/terms.

### 4. The purple-teal gradient is the documented, dated, #1 slop tell for our exact niche.
Adam Wathan (Tailwind) apologized Aug 2025 on X (x.com/adamwathan/status/1953510802159219096, 1M+ views) for defaulting Tailwind UI to bg-indigo-500, which trained every AI to output indigo. Separately, "cybersecurity" as a training token co-occurs with neon purple/cyan sci-fi imagery. So a cyber prompt pulls exactly the palette we must ban. Fix in code, not in prompts: an inline-SVG duotone (feColorMatrix collapse to luminance, then feComponentTransfer type=table remap to two brand hexes) forces every imported raster onto our palette regardless of what the generator produced. Working markup captured from css-tricks. Sources: K3 (prg.sh, css-tricks).

### 5. Generate ASSETS, not slides, and keep all type as real fonts.
The durable 2026 pattern (Kittl, weshop.ai, reallygooddesigns consensus): AI does mood/texture/background, real vector/type goes on top. This sidesteps AI's two worst failure modes (busy composition, garbled typography) and makes glyph-level AI-text detectors (TextFake, arxiv 2606.01050) irrelevant because our glyphs are real browser font rasterization. Recraft vector output specifically converts any text to path OUTLINES not live text, so we must generate the hero mark WITHOUT text and set type ourselves. This is already our architecture. Sources: K1, K2, K3.

### 6. Claude hand-writes the structural/data-driven SVG layer; the model makes only the one hero illustration.
LLM SVG is code generation, not design generation (svgmaker.io, 2026-04-13). Claude wins the infographic/geometric category (clean <g> groups, explicit font declarations, consistent viewBox, smaller files) but fails at illustrated characters and logos. So: hand-code SVG for anything simple, geometric, parametric, or data-driven (poster skeletons, thin rules, dividers, salary/save bars from real numbers, difficulty meters, badges in N cert colors). Cost: zero dollars, zero API calls. Chat2SVG (CVPR 2025) architecturally confirms the split: LLM builds semantic geometric structure, diffusion only adds detail. Note: benchmarks used Claude Sonnet 3.7, older than Carter's Opus, so real quality is likely understated. Sources: K2 (svgmaker.io, chat2svg.github.io).

### 7. Anti-slop is measurable audience behavior, and it validates the flat direction.
56% of consumers encounter AI slop frequently and want brands to stop (socibly 2026). Dominant 2026 trend is "Imperfect by Design." Flat intentional vector reads as authentic; glossy diffusion photoreal reads as slop (plastic sheen, too-perfect patterns, AI-shine on matte surfaces). Named tells to ban: purple/gradient blobs, Corporate Memphis / Alegria blob-people (declared dead, mockery-coded), pillow buttons, uniform soft shadows, stacked rounded corners. Malewicz's "Slopless" rule: plant a stake before touching the tool, and keep one deliberate human "weird" detail per deck. Sources: K2, K3 (socibly, Eidos "Slopless", Built In 2026-06-11, Creative Bloq).

### 8. Watermark/provenance reality: re-render helps but is NOT a guaranteed label-evasion.
Nano Banana Pro / Gemini (GA June 2026) and GPT Image 2 both stamp invisible SynthID + C2PA, and the Gemini consumer path adds a VISIBLE sparkle overlay that can trigger Instagram "Made with AI" labels. The named 2026 C2PA/SynthID embedders are OpenAI (ChatGPT/API/Sora), Google (Gemini/Nano Banana), Midjourney 2026 generations, Adobe Firefly, Leonardo, and Microsoft M365 (eyesift.com, thenextweb.com, c2pa.ai/instagram, verified this pass). Verified this pass: Instagram's "AI Info" / "Made with AI" label triggers PRIMARILY off the C2PA container manifest plus the IPTC `trainedAlgorithmicMedia` digital-source-type tag, automatically before any human review, at ~85-90% accuracy; Meta's AI Creator label rolled out May 4 2026 and EU AI Act Article 50 enforces Aug 2 2026 (c2pa.ai/instagram, aimetadatacleaner.com). Meta ALSO runs its OWN content-based classifier and perceptual-hash matching against known AI content, independent of metadata (eyesift 2026, aimetadatacleaner 2026). SynthID survives recompression, format conversion, and most cropping. So the shotpls re-paint drops C2PA/EXIF/IPTC (container-level) and a duotone+grain+crop degrades the visible sparkle, but a content classifier and a surviving in-pixel SynthID can still flag heavily-AI raster. Practical rule: this is why AI pixels belong only as a remapped/partially-occluded texture layer, never as the literal photographic subject, and why vector (Recraft SVG, has no pixels to watermark) is the safer primary. Do NOT build a watermark-stripping step: platform-flaggable and not worth the exposure. Sources: K1, K3, plus eyesift/aimetadatacleaner/c2pa.ai confirmed this pass.

### 9. fal.ai is the correct single integration layer.
One key gives Recraft V3/V4, Ideogram, FLUX.2, GPT Image 2, Nano Banana. Exclusive Recraft + Nano Banana access among aggregators, 30-50% cheaper than Replicate, Sync/Async/Queue(batch) modes, Python via litellm. One uv-managed client generates all asset types, then we SVGO + base64-inline into HTML for shotpls. Sources: K1 (fal.ai/learn, teamday.ai).

### 10. Ideogram 4.0 is the secondary pick and the self-host candidate.
Released June 3 2026, 9.3B open-weight Diffusion Transformer, commercial license, first among open-weight models on DesignArena, native bounding-box layout, 90-95% in-image text accuracy since 3.0. Use ONLY when text must be baked into a raster (stamped signage prop). Our own base64 fonts beat it for control on everything else. Its "editable layers out of inference" feature is ROADMAP not live (imagine.art), do not build against it. API $0.03 Turbo / $0.09 Quality. Sources: K1, K2.

### 11. Local generation is viable NOW; licensing is the gate, not hardware.
FLUX.2 klein 4B (Jan 15 2026, Apache-2.0, ~0.4s/image on a 4090, production-grade text) makes raster badge/emblem/book-cover assets nearly free, which is exactly Carter's proven winning style. LICENSE TRAP: klein 9B (higher quality) is Non-Commercial; only klein 4B is Apache-2.0. Commercial-safe local shortlist: FLUX.2 klein 4B (default), Qwen-Image (best open text, Apache, heavier), SDXL+LoRA+ControlNet (brand consistency). Path: warm headless ComfyUI over HTTP/WS API, launched with `--disable-dynamic-vram` to defeat the 2026 unload-after-every-gen regression; generate transparent-PNG subjects via LayerDiffuse/RMBG, composite in HTML. Honest limit: no local model matches Recraft's native-SVG + brand-consistency combo, so vector stays on Recraft API. Sources: K4.

### 12. FLUX.2 and the rest, ranked for us.
FLUX.2 (Nov 25 2025) is raster-only, no vector mode; strong photoreal/infographics; use only for occasional textured raster. GPT Image 2 has a FREE commercial license but the watermark tradeoff. Midjourney v7 needs a paid plan for any commercial right, has no real batch API, raster only: hand-made hero art only, not the pipeline. Sources: K1.

## DIRECTIVES FOR THE REBUILD (numbered, concrete)

1. NEVER generate a finished slide from any model. Every deck = hand-authored HTML/SVG layout + text zones, plus at most ONE wordless AI hero asset per slide. This is a hard architectural rule backed by GDB (font 23.7%, layout-text 33.5%, components 6.4% mAP).

2. Make Recraft V4/V4.1 Vector (via fal.ai, $0.08/vector) the primary asset engine. Prompt for "clear silhouettes, strong contrast, few colors, clean edges," ask for FEWER details than you think, and generate WITHOUT text so we set type ourselves. Use style-lock so a 10-slide deck reads as one set.

3. Be on a PAID Recraft/API tier before any commercial use. Free-tier Recraft assets are owned by Recraft and carry no commercial license (per ToS). Paid tier assigns full copyright to us.

4. Build ONE uv-managed fal.ai Python client with Queue/batch mode. It fires N asset gens per deck in parallel, downloads SVG/PNG, runs SVGO (AI-SVG preset: convertPathData, mergePaths, cleanupNumericValues, strips metadata/comments), then base64-inlines into the per-slide HTML. Fully offline at shotpls render time.

5. Add a `make-svg-asset` helper where Claude hand-writes the structural/data-driven flat SVG (poster skeletons, thin rules, dividers, badges in N cert colors, salary/save bars from real numbers, difficulty meters). Zero cost, zero API, and it is exactly Carter's thin-not-blocky editorial density.

6. Ship a reusable inline-SVG duotone filter in `<head>` plus a `.raster-brand` class the skill drops on EVERY imported raster, remapping it to two brand hexes automatically. This kills any purple-teal the generator produced and unifies a mixed-source deck. Add `filter: saturate(0.85-0.90)` to undo AI oversaturation.

7. Ship a `grain-overlay` component (full-bleed div, tiling noise data-URI or feTurbulence, mix-blend-mode soft-light, ~2-4% opacity) as the standard TOP layer of every raster composite. Grain is always last in the stack.

8. HARD-BAN list for prompts and output: purple/indigo/neon-cyan gradients, gradient blobs, Corporate Memphis/Alegria blob-people, pillow buttons, uniform soft shadows on every element, stacked rounded corners, ANY AI-rendered text/wordmark/label inside a raster, and human faces/hands from a generator without heavy duotone treatment.

9. Treat every AI raster as possibly-stamped. Never inline a raw generator PNG. Require duotone + grain + crop + shotpls re-render. Use AI pixels only as remapped, partially-occluded texture, never as the literal readable subject. Do NOT build a SynthID/C2PA stripping step (platform-flaggable). Prefer Recraft SVG (no pixels to watermark) as the primary path.

10. Keep ALL typography as real base64 fonts rendered by the browser. This is our structural moat: crisp poster type the generators cannot match, and it makes glyph-level AI-text detectors irrelevant. Never let a model set type.

11. Stand up local FLUX.2 klein 4B (Apache-2.0 only, NOT klein 9B) as a warm headless ComfyUI server on a random high host port, launched with `--disable-dynamic-vram`. Generate transparent-PNG badge/emblem/book-cover subjects (LayerDiffuse or generate-then-RMBG) for near-free image density on the proven artifact style. Vector stays on Recraft.

12. Plant one deliberate human "weird" detail per deck (Malewicz): an off-grid crop, a hand annotation, a real screenshot fragment, or a real artifact (badge render, book cover, terminal capture). Carter's own data says real artifacts already win; AI's job is to texture and unify them, never to synthesize the subject.
